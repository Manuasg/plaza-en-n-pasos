Los números reales no negativos $a_1, a_2, \dots, a_n$ cumplen las condiciones
$$a_1 + a_2 + \cdots + a_n = 2n, \qquad \binom{a_1}{2} + \binom{a_2}{2} + \cdots + \binom{a_n}{2} = n.$$
Probar que $a_i = 2$ para todo $i = 1, 2, \dots, n$.
> Como los $a_i$ son reales, $\binom{a}{2}$ significa $\frac{a(a-1)}{2}$. Reescribe la segunda condición en términos de $\sum a_i^2$.
> Calcula $\sum (a_i - 2)^2$ con las dos condiciones.
---
**Planteamiento.** Para un real $a$, $\binom{a}{2} = \frac{a(a-1)}{2}$. La idea es transformar las dos condiciones en una suma de cuadrados igual a cero.

**Desarrollo.** La segunda condición equivale a
$$\sum_{i=1}^n \frac{a_i^2 - a_i}{2} = n \iff \sum a_i^2 - \sum a_i = 2n \iff \sum a_i^2 = 2n + 2n = 4n.$$
Entonces
$$\sum_{i=1}^n (a_i - 2)^2 = \sum a_i^2 - 4\sum a_i + 4n = 4n - 8n + 4n = 0.$$
Una suma de cuadrados de números reales es nula si y solo si cada sumando es nulo, luego $a_i - 2 = 0$ para todo $i$.

**Conclusión.** $a_i = 2$ para todo $i = 1, \dots, n$. $\blacksquare$

**Comprobación.** Con $a_i = 2$: $\sum a_i = 2n$ y $\sum \binom22 = n$. ✓ La hipótesis de no negatividad no hace falta en este argumento.

**Comprobación.** Si $x>0$: $\int_0^x a\,dt = ax = x f(x)$. Si $x<0$: $\int_0^x b\,dt = bx = xf(x)$. ✓

$$f(x) = \begin{cases} a & x>0\\ c & x = 0\\ b & x<0\end{cases}\qquad a, b, c\in\mathbb{R} \text{ arbitrarios}.$$

Demuestra que $\operatorname{mcd}(n^2+1,\ n+1)\in\{1,2\}$ para todo $n\in\mathbb{Z}$ y determina cuándo vale 2.
> Divide $n^2+1$ entre $n+1$.
> $\operatorname{mcd}(a,b) = \operatorname{mcd}(b, a - qb)$.
---
$n^2 + 1 = (n+1)(n-1) + 2$, así que
$$\operatorname{mcd}(n^2+1, n+1) = \operatorname{mcd}(n+1, 2)\in\{1,2\}.$$
Vale 2 si y solo si $n+1$ es par, es decir, **si $n$ es impar**. $\blacksquare$
!! Afirmar el resultado con unos ejemplos sin usar la propiedad del algoritmo de Euclides.
